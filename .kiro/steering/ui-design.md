# UI デザイン（TACTICAL LINK）

すべての画面を、MS のコックピットの計器としてそろえる。3D ビューの HUD で使ってきた水色を主役にし、練習・コマンド・譜面作成・設定・機体選択まで同じトークンと部品で組む。

- トークン: `next/src/styles/theme.css`
- デザインボード（トークン・部品・画面例の見本）: https://claude.ai/artifact/JpxC8VJgGzYbXkNZWu4Ub6
- 新しい画面や部品を作るときは、まずボードと既存の部品（`src/components/`）を見て、同じものを使う

## 3 つの決まりごと

1. **アクセントは水色ひとつ**。押せるもの・選んでいるもの・自分の数値は `--cyan` / `--cyan-hi`。`--ok`・`--warn`・`--danger`・`--awaken` は意味を伝えるときだけ使い、飾りにしない
2. **角は斜めに切る**。パネル・ボタン・チップ・モーダルは左上と右下を `--cut-*` で落とす（`clip-path`）。丸いピル形は使わない。円はアケコンのボタンとタッチのスティックだけ。斜めに傾けるのはブーストゲージだけ（`--skew-gauge`）
3. **書体は M PLUS 1 と M PLUS 1 Code の 2 つだけ**。見出し・ラベル・本文は M PLUS 1（`--font-body` / `--font-label`）で、太さで役割を分ける（技名 800、見出しとラベル 700、本文 400）。数字とコードは等幅の M PLUS 1 Code（`--font-num`）

## 色

| トークン | 使いどころ |
| --- | --- |
| `--ink-0` | いちばん奥の背景 |
| `--ink-1` | パネル・モーダル・ヘッダー |
| `--ink-2` / `--ink-3` | カード・副ボタン / そのホバー |
| `--glass` | 3D の上に重ねる帯・ボタン |
| `--line` / `--line-strong` | 飾りの枠・区切り / 押せるもの・入力欄の枠 |
| `--cyan` / `--cyan-hi` / `--cyan-deep` | 主アクセント / 数値・選択中の文字 / ゲージの下端・技名の帯 |
| `--text` / `--text-muted` / `--text-dim` | 本文 / 補足 / OFF など目立たせない表示 |
| `--ok` / `--warn` / `--danger` / `--awaken` | 成功・接続済み / 待機・注意・コスト / 失敗・被弾・削除 / 換装・時限強化 |
| `--btn-red` / `--btn-blue` / `--btn-green` | アケコンの射撃・格闘・ジャンプのボタンだけ |

- 状態は色だけで伝えず、必ず文字も出す（接続中・待機中・切断、ON / OFF）
- 色を CSS に直書きしない。3D の描画（three.js の材質や弾の色）と、機体データの機体色だけは例外
- 旧テーマのトークン（`--surface-*`、`--led-*`、`--btn-yellow`、`--color-*` など）は新しい値に向けて残してある。新しく書く CSS では使わず、上の新しい名前を使う

## 3D ビュー（トップ `/`）

- 画面は 3D と HUD だけ。ほかは上端の帯（接続状態・機体・設定）と設定モーダルへ
- ブーストゲージは画面の中央下、斜めの水色のゲージ
- 残弾は画面の右下に武装ごとの札を縦に積む。使うコマンドとチャージの途中経過も札に出す
- 画面中央の技名は許可リストにあるものだけ（`unit-authoring.md` を参照）。帯は水色、出せなかった理由は赤い小さな文字
- タッチ操作中は HUD を右上に縦に積み、レバーは左下、ボタン 3 つは練習画面と同じ大きさで右下に置く

## 練習・コマンド・ツールの画面

- 地は `--ink-0` に薄い水色のグリッド（`globals.css` の `body::before`）
- ヘッダーは `--glass` の帯に `--line` の下線。右上に固定のメニューボタンが重なるので、ヘッダーの右は 4rem 空ける
- 練習中の手順は、できたものを `--ok`、いまの手順を `--cyan-hi` で示す

## 書き方

- ボタンは何が起きるかを動詞で書く（「接続する」「削除する」「ルームを作り直す」）
- 技名・コマンド名は EXVS で通じる呼び方のまま（ズンダ、ステキャン、BDC、射CS）
- 絵文字は使わない
