# Requirements Document

## Introduction
エクバコマンド練習アプリ（コマンドトレーナー）のUIを、エクストリームバーサス公式サイトのビジュアルを参考にした「メカゲームHUD」スタイルに刷新する。ディープネイビー背景＋横スキャンライン、カプセル型メタリックボタン（両端シアンキャップ）、白抜き太字テキストを基軸とし、ゲームの世界観に直結したビジュアル体験を提供する。

## Boundary Context
- **In scope**: アプリ全体のカラーテーマ・スタイリング・アニメーション・タイポグラフィの刷新、アーケードコントローラUIの視覚的改善
- **Out of scope**: 機能ロジック・状態管理・データ構造の変更、新規機能の追加、バックエンドとの連携
- **Adjacent expectations**: 既存の練習モード・コマンド一覧等の機能は維持したまま、UI層のみを変更する

## Requirements

### Requirement 1: カラーパレットとデザイントークン
**Objective:** As a プレイヤー, I want アプリ全体が公式サイト準拠の青系メカゲームカラーで統一されていること, so that ゲームの世界観に直結した視覚体験を得られる

#### Acceptance Criteria
1. The コマンドトレーナー shall 以下のカラートークンを CSS カスタムプロパティとして `src/styles/` 配下の単一ファイルで定義する：ベース背景（ほぼ黒のネイビー `#050a14` 相当）・中間背景（ダークネイビー `#0a1628` 相当）・プライマリアクセント（明るいシアン `#4fc8e8` 相当）・セカンダリアクセント（ディープシアン `#1a6080` 相当）・テキスト白（`#e8f4f8` 相当）
2. The コマンドトレーナー shall 全カラートークンを全コンポーネントから CSS 変数として参照できるようにする
3. When ページが読み込まれた時, the コマンドトレーナー shall 全ページでディープネイビー背景を表示する
4. The コマンドトレーナー shall プライマリアクション要素にシアンアクセントカラーを適用する

### Requirement 2: タイポグラフィとテキストスタイル
**Objective:** As a プレイヤー, I want 公式サイトに近いゲームらしい太字・ゆったり字間のテキストスタイルを体験できること, so that アプリのビジュアルトーンがゲームと一体感を持つ

#### Acceptance Criteria
1. The コマンドトレーナー shall 見出し・ボタンラベルに太字（`font-weight: 700` 以上）を適用し、`letter-spacing: 0.1em` 以上の字間を設定する
2. The コマンドトレーナー shall 重要な見出し・スコア表示に CSS `text-shadow` を用いたシアン系グロー効果を適用する
3. The コマンドトレーナー shall 日本語テキストの可読性を維持するため、本文にはシステムフォントまたはサンセリフフォントを使用する
4. The コマンドトレーナー shall テキストカラーにオフホワイト（`#e8f4f8` 相当）を基本色として使用する

### Requirement 3: カプセルボタンコンポーネント
**Objective:** As a プレイヤー, I want 公式サイト準拠のカプセル型メタリックボタンを操作できること, so that ゲームのUIと同じ質感を感じながら操作できる

#### Acceptance Criteria
1. The コマンドトレーナー shall プライマリボタンをピル/カプセル形状（`border-radius` を高さの半分程度）で実装する
2. The コマンドトレーナー shall ボタン本体にダークネイビーから中間ネイビーへの縦グラデーションを適用する
3. The コマンドトレーナー shall ボタン両端に明るいシアン色の縦帯アクセント（端キャップ）を疑似要素または内部要素で表現する
4. When ユーザーがボタンにホバー・フォーカスした時, the コマンドトレーナー shall ボタン全体のシアンアクセントを明るくし、`box-shadow` グロー効果を適用する
5. When ユーザーがボタンを押下した時, the コマンドトレーナー shall ボタンが僅かに暗くなり押下感のビジュアルフィードバックを提供する
6. If フォームの入力値が無効な場合, the コマンドトレーナー shall エラー表示にアンバー/レッド系のアクセントを使用する

### Requirement 4: カードとコンテナコンポーネント
**Objective:** As a プレイヤー, I want コンテンツカードがゲームのHUDパネルのような外観で表示されること, so that 情報が整理されながらも世界観が維持される

#### Acceptance Criteria
1. The コマンドトレーナー shall カードコンポーネントにダークネイビー半透明背景とシアン系の細いボーダーを適用する
2. The コマンドトレーナー shall ナビゲーション要素（ヘッダー・リンク・パンくずなど）をメカゲームHUDスタイルで表示する
3. The コマンドトレーナー shall セクション区切りにシアン系の薄いラインを使用する

### Requirement 5: バックグラウンドとスキャンラインテクスチャ
**Objective:** As a プレイヤー, I want 公式サイトと同様の横スキャンライン背景テクスチャが表示されること, so that メカゲームの世界観が視覚的に強調される

#### Acceptance Criteria
1. The コマンドトレーナー shall 全ページに上部ほぼ黒・下部ダークテール方向の縦グラデーション背景を適用する
2. The コマンドトレーナー shall 背景に CSS `repeating-linear-gradient` または `background-image` で実装した横スキャンライン（細い水平線の繰り返し）テクスチャを重ねて表示する
3. The コマンドトレーナー shall スキャンラインテクスチャの透明度を 5〜15% 程度に留め、コンテンツの視認性を損なわないようにする
4. If デバイスが `prefers-reduced-motion: reduce` を指定している場合, the コマンドトレーナー shall アニメーション付き背景エフェクトを無効化する

### Requirement 6: アーケードコントローラUIのビジュアル改善
**Objective:** As a プレイヤー, I want アケコンUIのボタンがメカゲームHUDスタイルのネオン発光で表示されること, so that 入力フィードバックが直感的で没入感が高まる

#### Acceptance Criteria
1. The コマンドトレーナー shall アーケードコントローラの各ボタン（射撃・格闘・ジャンプ等）にシアン系のアウトラインとグロー効果を適用する
2. When ユーザーがボタンを押下した時, the コマンドトレーナー shall ボタンのグロー効果を強調し、押下フィードバックを視覚的に表示する
3. While 練習セッションが進行中の時, the コマンドトレーナー shall 成功入力ボタンに緑系ネオングロー、失敗入力ボタンに赤系ネオングローを適用して状態を区別する
4. The コマンドトレーナー shall スマートフォン横画面（landscape）でコントローラUIのスタイルが崩れずに表示される

### Requirement 7: アニメーションとマイクロインタラクション
**Objective:** As a プレイヤー, I want 操作に応じた滑らかなゲームHUD調アニメーションを体感できること, so that ゲーム的な爽快感と没入感が高まる

#### Acceptance Criteria
1. The コマンドトレーナー shall インタラクティブ要素のトランジション時間を 150ms〜300ms に設定し、`ease-out` または `cubic-bezier` カーブで制御する
2. When コマンド練習の成否が判定された時, the コマンドトレーナー shall 結果表示にフラッシュ・パルス等のネオンアニメーションを適用する
3. The コマンドトレーナー shall ページ遷移にフェードまたはスライドのトランジションを適用する
4. If デバイスが `prefers-reduced-motion: reduce` を指定している場合, the コマンドトレーナー shall 全アニメーションをカット・または duration 0ms にフォールバックする
