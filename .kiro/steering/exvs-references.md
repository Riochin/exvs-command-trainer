# EXVS の参照元

入力リレーの 3D ビュー（`next/src/features/input-relay/`）で機体の武装・キャンセルルート・テクニックを再現するときに見る一次情報。機体を足すときは、ここに挙げたページだけを根拠にする。別の wiki やブログの情報を使ったら、その URL をこの文書に足す。

## 一覧

| 用途 | ページ | URL |
|------|--------|-----|
| 機体ごとの武装・キャンセルルート（第一の参照元） | EXVS2 INFINITEBOOST wiki 機体ページ | 例: ストライクルージュ(オオトリ装備) https://w.atwiki.jp/exvs2infiniteboost/pages/117.html |
| 機体ページを探す | EXVS2 INFINITEBOOST wiki 機体一覧 | https://w.atwiki.jp/exvs2infiniteboost/pages/123.html |
| BD・ステップ・慣性ジャンプ・BD旋回・着地硬直などの共通仕様 | EXVS2 wiki システム | https://w.atwiki.jp/exvs2/pages/12.html |
| テクニック（ズンダ・ステキャン・アメキャン・滑り特射・BD旋回・落下テクなど） | EXVS MAXI BOOST ON wiki テクニック | https://w.atwiki.jp/gundamexvsmbon/pages/258.html |

## 機体ページ（EXVS2IB wiki）の読み方

機体ページはおおむね次の順で並んでいる。機体データ（`UnitDef`）のどこに写すかは `unit-authoring.md` の対応表を参照。

1. **基本情報の表**: コスト・BD 回数（「通常時：6 / SEED発現時：8」のように形態ごと）・形態移行・パイロット・作品枠
2. **武装の一覧表**: 射撃（メイン・CS・N/横/後サブ・特射・後格など）と格闘（N格・前格・横格・BD格・派生・特格）の名称・弾数・入力
3. **キャンセルルート**: 「メイン→各サブ、後格」「各特射→メイン」のように、どの技からどの技へキャンセルできるか。時限強化中だけのルートは別見出し
4. **武装ごとの解説**: 動き（足が止まるか、移動撃ちか、照射か）、アメキャン対応か、リロードの表（「常時/3秒」「撃ち切り/14秒」など）

## 注意

- **作品版ごとの差**: 武装・キャンセルルート・弾数は作品版（EXVS2、XBOOST、OVERBOOST、INFINITEBOOST、MBON）ごとに変わる。このプロジェクトは **EXVS2 INFINITEBOOST（IB）を基準**にする。IB wiki に無い機体だけ、ほかの版の wiki を使い、どの版の情報かを機体ファイルの先頭のコメントに書く。
- **共通仕様とテクニックは古い版のページを使っている**: システムは EXVS2 wiki、テクニックは MBON wiki。IB でも大筋は同じだが、細かな仕様（慣性の残り方など）は版で違うことがある。機体ページの記述と食い違ったら機体ページを優先する。
- **数値は wiki に無いことが多い**: 弾速・誘導・発生フレーム・硬直・移動距離などはほとんど書かれていない。書かれていないものは汎用機（`sim/actions.ts` の `ACTIONS`）の値を出発点に、見た目で調整する。調整した値には「実機の値は未確認」とコメントを残す。
- **扱わないもの**: 威力・補正率・ダウン値・よろけ値・耐久値・覚醒技は再現しない。慣性の残り方は機体ごとに変えず共通にする（`sim/actions.ts` の定数）。
- **wiki の更新**: wiki はアップデートで書き換わる。機体を足したときの URL と確認日を、機体ファイルの先頭のコメントに書いておく。

## ページの読み方（Claude Code から）

- atwiki は **WebFetch だと 403** になる。アプリ内ブラウザ（`mcp__Claude_Browser__navigate` で開き、`mcp__Claude_Browser__get_page_text` で本文を取る）で読む。
- 機体ページは長いので、`get_page_text` は `max_chars` を大きめ（30000 程度）にするか、何回かに分けて読む。武装の一覧表とキャンセルルートはページの前半にある。
- 見出しの一覧だけ欲しいときは、同じタブで `mcp__Claude_Browser__javascript_tool` から `fetch(url)` して `<h2>`〜`<h4>` を抜き出すと速い（atwiki のページを開いているタブからなら取れる）。
